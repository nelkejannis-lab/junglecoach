# Jungle Coach für iPhone

Die App zeigt die mobile Web-App (`/m/` auf dem Jungle-Coach-Server) und übernimmt den Login per Google/Discord.

**Bauen:** GitHub Actions → „iOS app“ → baut `JungleCoach-unsigned.ipa` (ohne Signatur).

**Installieren (ohne App Store):** IPA mit Sideloadly oder AltStore und deiner Apple-ID aufs iPhone laden.
Mit einer kostenlosen Apple-ID läuft die Signatur nach 7 Tagen ab (einfach neu laden), mit dem
Apple Developer Program (99 €/Jahr) 1 Jahr bzw. über TestFlight/App Store.

**Ohne App:** `https://junglecoach.nelkejannis.workers.dev/m/` in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
